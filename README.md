# 网页搜索插件

作者：ayacyann

为 AstrBot 提供只读联网搜索、网页正文读取和常用数据查询能力，搜索结果可交给当前聊天模型总结。

## 当前功能

### 通用网页搜索

- 支持联网搜索公开信息。
- 支持读取搜索结果页面的正文。

### 代码仓库搜索

- 支持按名称搜索公开代码仓库。
- 返回仓库基本信息，并读取仓库说明文档正文。

### 创作者搜索

- 支持按创作者名称搜索公开账号。
- 返回账号公开信息和最近投稿的标题。

### 天气查询

- 支持查询指定城市的当前天气。
- 返回当前气温、体感温度、湿度、降水量和风速。
- 返回未来三天的天气概况。

### 安全边界

- 拒绝明显违法、危险、侵犯隐私或绕过访问限制的搜索请求。
- 不访问本机、内网或保留网段。
- 不下载、不保存、不执行网页中的任何文件。
- 只读取公开网页正文，不修改目标页面。

## 配置项

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `max_results` | 每次搜索返回给模型的结果条数，范围 1-20 | `7` |
| `fetch_pages` | 是否读取页面正文 | `true` |
| `max_pages` | 每次最多抓取几个页面正文 | `4` |
| `page_timeout_seconds` | 单个页面正文抓取超时时间（秒） | `15` |
| `max_page_chars` | 单个页面最多交给模型的正文字符数 | `5000` |
| `block_unsafe_queries` | 拒绝违规、危险或侵犯隐私的查询 | `true` |

## 说明

- 当前聊天模型需要支持工具调用。
- 搜索与正文读取会消耗当前模型的上下文 token。
- 搜索结果和网页内容来自公开互联网，准确性以原始来源为准。
